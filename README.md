# Telegram-бот для записи на бьюти-услуги

Полноценный бот на **aiogram 3.x** + **SQLAlchemy** (SQLite / PostgreSQL) для записи клиентов на маникюр, педикюр и реснички.

## Возможности

### Клиентская часть
- Пошаговая запись на услуги через FSM
- Для маникюра — детальный опрос (покрытие, состояние ногтей, длина, дизайн, когти, формат общения)
- Динамический пересчёт длительности и цены после каждого выбора
- Выбор даты из календаря и свободных слотов
- Подтверждение с точным временем начала и окончания
- Напоминание за 3 часа до записи
- Управление своими записями (просмотр / отмена)
- Разделы: Прайс, Правила, Соцсети, «Для тех, кто идёт впервые», «Про формы ногтей»

### Админ-панель (`/admin`)
- Записи на сегодня / на месяц
- Статистика (выручка + количество клиентов)
- Управление расписанием (открытие/закрытие дней)
- Управление услугами
- Редактирование всех текстовых блоков

## Быстрый старт

1. Клонируйте / скопируйте проект
2. Создайте виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/Mac
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Создайте `.env` на основе `.env.example`:
   ```bash
   cp .env.example .env
   ```
   Укажите `BOT_TOKEN` и свои `ADMIN_IDS`.

5. Запустите:
   ```bash
   python main.py
   ```

## Часовой пояс

Бот использует `Europe/Moscow` (Казань) независимо от сервера (Нидерланды).

## Расширение

Все коэффициенты времени и цены хранятся в таблице `service_parameters`.  
Новые услуги и шаги можно добавлять через админку / напрямую в БД.  
Архитектура позволяет легко добавлять новые `step_code` и услуги без изменения логики хендлеров.

## Важно

- Замените `ADMIN_IDS` в `.env` или `config.py` на свои Telegram ID.
- Для продакшена рекомендуется PostgreSQL.
- Напоминания проверяются каждую минуту через APScheduler.


## Google Calendar (опционально)

1. Google Cloud Console → создать проект → включить **Google Calendar API**
2. Service Account → скачать JSON-ключ → положить в `data/google_credentials.json`
3. В Google Calendar: Настройки календаря → «Доступ для отдельных пользователей» → email сервис-аккаунта с правом **вносить изменения в мероприятия**
4. В `.env`:
```
GOOGLE_CALENDAR_ENABLED=true
GOOGLE_CALENDAR_ID=primary
GOOGLE_CREDENTIALS_FILE=data/google_credentials.json
```
(или ID календаря из настроек «Интеграция календаря»)

После подтверждения предоплаты событие появится в календаре. При отмене — удалится.
